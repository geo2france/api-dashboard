# Theming

Le theming repose sur deux réglages simples :

- `theme` choisit la palette de couleurs (`geo2france` ou `neutral`).
- `themeMode` choisit la luminosité (`light`, `dark` ou `auto`) dans `config.ts`.
- `mode` choisit la luminosité uniquement si vous utilisez `<ThemeProvider>` directement.

Ces deux réglages sont combinables librement.

Si vous avez besoin d'une identité visuelle complète (couleurs, logo, typographie), utilisez `visualIdentity` (voir la page **[Identité Visuelle](?path=/docs/documentation-identite-visuelle--docs)**). Quand `visualIdentity` est fourni, il est prioritaire sur `theme`.

## Configurer le thème

### Via `config.ts` (recommandé)

```ts
// config.ts
export const config: DashboardConfig = {
  theme: "geo2france", // ou "neutral"
  themeMode: "auto",
};
```

### Via `<ThemeProvider>` directement

Si vous intégrez la bibliothèque dans une application React existante sans passer par `DashboardApp` :

```tsx
import { ThemeProvider } from '@geo2france/api-dashboard';

export default function App() {
  return (
    <ThemeProvider theme="neutral" mode="light">
      {/* votre application */}
    </ThemeProvider>
  );
}
```

## Logo et identité visuelle personnalisée

Le logo du tableau de bord est configuré dans `config.ts` via la propriété `logo` (voir la doc `DashboardApp`). Il est indépendant du preset de thème.

```ts
export const config: DashboardConfig = {
  theme: "neutral",
  logo: "/mon-logo.svg",
};
```

## Note pour les contributeurs

> **Règle critique Ant Design v6 : ne mettez jamais de couleurs dans `baseTokens`.**
>
> Le `darkAlgorithm` d'Ant Design ne peut pas écraser les tokens couleur définis dans la configuration de base ([issue #53719](https://github.com/ant-design/ant-design/issues/53719)). Toutes les couleurs sont donc définies exclusivement dans les palettes (`tokens/palettes/`) et les thèmes complets (`themes/`).
